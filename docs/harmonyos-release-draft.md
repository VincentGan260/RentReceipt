# 鸿蒙上架资料草案

状态：2026-10-17，本地功能补齐与验收阶段；尚未提交市场审核。以下是候选文案，最终发布前核对真机结果、备案及 AGC 资质流程。

## 商店介绍

应用名：租簿

一句话简介：离线管理房租、水电和押金，生成收据并备份账本。

详细介绍：

租簿帮助房东按楼栋管理房间，记录每月水电读数、房租、押金和其他费用，并查看收租情况。

- 按楼栋设置水电及公共服务费，也可为房间单独设置价格。
- 支持表具归零、换表实际用量、入住首月房租与漏月补收。
- 查看历史账单，生成高清收据，保存到相册或主动分享。
- 按月份范围导出房东留档 PDF，使用 ZIP 备份迁移数据。
- 手机与折叠屏自适应，支持深浅主题和界面大小设置。

应用无需账号，无广告，业务数据保存在本机。请在换机、卸载或清除数据前导出备份。

## 隐私政策草案

租簿不设置账号，不接入广告、分析或远程崩溃上报服务，不申请网络访问权限，不将房间、金额、读数或账单上传到服务器。

你输入的业务资料及未完成草稿保存在应用私有存储。本机外观偏好仅用于展示设置。卸载或清除应用数据会删除这些记录。

当你主动导入或导出文件时，应用调用系统文件选择器，仅访问你选择的文件或保存位置。导入需要在应用内再次确认，覆盖全部业务资料和未完成草稿。

当你保存收据到相册时，由系统弹窗确认保存；应用不读取你的整个相册。当你主动分享图片时，由系统分享面板将选定图片交给你指定的应用，后续处理遵循该应用的隐私政策。

ZIP 备份和图片/PDF 可能包含房号、费用、押金和账单记录，请自行妥善保管。应用不收集定位、通讯录、手机号、身份证号或支付账户，也不提供在线支付。

联系渠道、政策生效日期、开发者展示名称和公开政策地址：发布前由开发者确认后填写；当前草案不可直接作为最终公开政策发布。
