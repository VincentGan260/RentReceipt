## 已确认差异

- 2026-10-18 用户确认：三端录入统一正常水电计费。历史仅房租账单在未编辑时保留原数据；重新录入时按正常计费处理。
- 押金状态切到已收 / 已退，按 Android 方式记录当天；重复选择同一状态不改日期。
- ZIP 中电表归零上限为空时保留空值，避免恢复改变计费规则。
- 批量收租支持已收 / 未收双向，修改前确认；只作用当前楼栋当前月。
- Android 专属玻璃导航、动态配色、预测返回等采用鸿蒙原生对应交互；保留主题、大小、动画与重置功能。

## 实现边界

- ZIP 和现有两端一样，不携带未完成草稿及本机外观；导入会覆盖全库，确认前不写入。
- PDF 为 A4 横向图像版式加 Unicode 文字层，支持搜索、选择和复制；表格线条和文字外观仍为图像。每次最多 120 个月 / 100 页，可分段导出。
- 相册写入使用系统确认，无全图库读取权限；文件导入导出使用系统选择器。应用不申请网络权限。
- 不能用“功能已有入口”“构建成功”代替原生文件结果、取消 / 失败分支、真机和最低系统验证。
