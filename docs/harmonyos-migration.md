- 用户已提供真机，曾安装调试包成功；尚未完成真机功能验收，最低系统仍需覆盖。

## 已发现的差异，待确认

Android AppearanceSettingsScreen 提供显示模式、界面大小、动画、预测返回、重置以及关于/许可入口；当前 iOS Swift 源码搜索未发现对应独立设置入口。建议鸿蒙保留显示模式、界面大小、动画、重置和关于/许可，返回采用鸿蒙系统导航，不新增 Android 预测返回开关。用户已于 2026-10-14 确认此方案。

## 业务基础层完成情况

- 已移植 PricingSettings、Building、Room、Bill、BillDraft、收费项与收据模板；默认模板的 29 个元素来自当前 Android 模型。
- 使用十进制字符串算术实现加减、乘法、比较和 HALF_UP 舍入，金额不经过二进制浮点转换。单个数字输入长度/指数设有上限，超限明确报错。
- 已实现单价覆盖、公共服务费、入住首月、表具归零/换表、漏月房租合并、固定收费选择与账单字段生成。
- 用户已确认首月规则：不合并漏月房租时保留 rentOnly；确认合并时切回正常水电计算。这是已批准的平台差异。
- 存储层包括楼栋、房间、账单、草稿与收租状态操作；出账更新保留已有账单 ID 与收款记录。
- 删除房间保留历史账单，并清理已无法访问的该房间草稿；删除楼栋级联删除关联数据与草稿，支持全空状态后重新创建。
- 将数据与草稿写入同一个应用私有 JSON 快照；串行提交避免覆盖；存储失败不发布新内存状态，损坏/未知版本快照不回退为空数据。ZIP v10 尚未接入。
- 启动加载与后台 flush 已接入 UIAbility；概览、录入、房间管理及其编辑/历史/收租入口已接入。

验证：29 项测试通过。其中算术随机测试包含 1200 组独立 BigInt 固定小数对照，跨平台测试包含 80 组输入，直接编译当前 iOS Swift 模型/计算器并逐字段比较账单结果。Android 样例来自现有 BillCalculationTest（本次没有重新运行 Android 构建）。主机文件测试模拟短写、写入失败、同步失败和重命名失败，验证原文件保留与重试；不代表鸿蒙文件接口已在设备上通过验证。

后续顺序：ZIP v10 跨平台备份、收据与 PDF 导出、外观设置、更多设备与系统版本验证、发布材料。
