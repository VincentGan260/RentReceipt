# 鸿蒙主页面与折叠屏验证记录

日期：2026-10-14。当前版本为开发版本，未准备正式签名或提交市场审核。

## 实现范围

概览、录入、房间三个标签页；楼栋选择与搜索；楼栋新增/改名/默认单价/删除；房间新增/编辑/删除、出租状态、押金及日期、独立水电/公共服务费/表具上限、固定费用；历史账单与详情；单间收租和批量已收；自动存草稿和出账；归零/换表输入；漏月房租确认合并。

使用 ArkUI 原生组件与系统导航。界面按窗口宽度变化：首页一至三列，录入最多两列。宽屏打开编辑/详情时使用 Navigation 双栏，未打开详情时首页铺满窗口。表单可滚动，跟随系统深浅色。

押金日期采用用户确认的 Android 方式：状态切换为已收或已退时记录当天。同一状态再次选择不改日期。首月计费按之前确认的规则实现。

## 测试发现并修正

- Select 的选中索引未自动显示楼栋名称：显式绑定当前名称。
- 次要按钮默认使用强调色：使用原生 NORMAL 样式与统一圆角。
- ForEach 复用旧卡片导致已出账/付款状态未刷新：卡片按内容生成更新标识，录入单独保留稳定草稿缓存。
- 月份标题按 Builder 值参数未刷新：改为直接读取响应式月份；账单详情动态行使用 @Prop。
- Navigation Auto 在宽屏无详情时出现空右栏：只有打开详情时使用 Auto，首页采用全宽模式。
- 折叠录入三列使长房号换行不自然：录入限制为两列，普通房间卡片仍按窗口宽度自适应。

设备管理器的“找不到系统镜像”提示与实际可启动状态不一致；没有重新下载镜像。手机已启动并连接，折叠屏旧快速启动快照加载失败，通过官方工具 coldboot 和独立 hdc 端口 10001 完成验证。没有使用 reset 或删除设备数据。

电脑界面工具无法识别独立模拟器窗口后，用户明确授权改用官方 hdc / uitest。辅助脚本 tools/harmonyos-ui.py 根据当前界面树查找控件，不使用预设表单坐标；输入前全选替换并核对字段结果。

已检查手机测试进程的错误日志；折叠端曾出现系统 CONCUR 调度 QoS 错误日志，已执行流程中未观察到应用退出或 JS 异常。此记录不是对所有系统日志的无错误保证。
