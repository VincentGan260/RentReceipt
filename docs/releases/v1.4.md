# 租簿 RentReceipt v1.4

- 修改楼栋或房间收费后，可确认重新计算并导出所选月份的房租单；选择“暂不导出”时保留原账单。
- 重新计算时保留实际水电用量、收款记录和手工附加收费，不影响其他月份。
- 修复清空水电录入后仍能导出旧房租单的问题，补全读数后可重新生成。
- iOS、鸿蒙新增录入“继续”操作，按顺序跳到下一处未填写的水电读数。
- Android：优化键盘“继续”时的滚动位置，修复“暂不导出”可能闪退的问题。
- Android：改善弹窗背景模糊效果，统一设置页卡片、字号与颜色；不支持模糊时使用不透明背景，改善 Android 12 显示效果。
- 鸿蒙：修复部分旧系统启动退出的问题，改善二级页面底部背景及编辑页按钮布局。
- iOS、鸿蒙：修复恢复换表账单后实际用量可能丢失的问题。

本次提供 Android 安装包，可覆盖升级旧版。升级前建议先导出备份。

iOS 和鸿蒙本次仅更新源码，暂不提供安装包；鸿蒙版仍在适配完善中。
