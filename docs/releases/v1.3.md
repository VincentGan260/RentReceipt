# 租簿 RentReceipt v1.3

- Android：搜索房间更方便，输入房号即可筛选，支持一键清空和退出搜索。
- Android：优化底部导航的选中动画。
- iOS：新增搜索入口，可快速查找概览、录入和房间页面中的房号。
- 优化金额、单价和表具上限的输入提示，减少填错信息的情况。
- 修复删除房间或恢复备份后，旧的录入内容仍然出现的问题。
- 修复电表上限留空后未能正确保留设置的问题。
- iOS：修复重复标记已收款时改变原收款日期的问题，完善押金日期记录。
- 优化收据中的单价展示。

本次提供 Android 安装包，可直接覆盖升级 v1.1、v1.2。升级前建议先导出备份。

iOS 和鸿蒙本次仅更新源码，暂不提供安装包；鸿蒙版仍在适配完善中。
