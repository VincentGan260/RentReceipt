# 跨会话项目摘要

更新日期：2026-10-20

## 产品与平台

租簿（RentReceipt）用于房东管理楼栋、房间、抄表出账、收租、收据图片/PDF 和 ZIP 备份恢复。业务数据保存在用户设备本地。

仓库包含 Android、iOS 和正在适配的原生 HarmonyOS 客户端。详细功能与数据格式以根目录 `README.md` 及各平台源码为准，避免在此重复维护。
